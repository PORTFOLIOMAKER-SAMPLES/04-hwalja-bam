## 이 견본이 쓴 설정

| | |
|---|---|
| 구성 | **한 장짜리 원페이지** — 상단 메뉴가 페이지가 아닌 *섹션*을 가리킵니다 |
| 테마 | 버건디 |
| 글꼴 | Instrument Serif |
| 레이아웃 | 상단 헤더 + 왼쪽 프로필 Aside + 벤토 조합 |
| 3D | `projector.glb` |
| 효과 | 호버 프리뷰 · 스크롤 등장 · 틸트 카드 · 패럴랙스 · 부드러운 스크롤 |
| 작업물 | 8점 (책 · 견본첩 · 시집 · 정기 구독) |
| 사진 | 8장 |
| 용량 | 약 5.8 MB |

메뉴를 **「이 페이지 섹션」** 으로 두면 페이지를 늘리지 않고도 목차가 생깁니다.
여덟 개 견본 중 유일하게 한 장으로만 이루어진 구성입니다.
아래쪽에는 작업 용어가 흐르는 마퀴 띠가 지나갑니다.

## 직접 열어서 뜯어보기

1. [portfoliomaker.site](https://portfoliomaker.site) 접속
2. 상단 **저장 · 불러오기** 아이콘 클릭
3. **파일에서 불러오기** → 이 저장소의 `hwalja-bam.pbproj` 선택

## Portfolio Maker 는 어떤 도구인가요

- **설치 없음 · 가입 없음** — 브라우저에서 바로 시작합니다
- **틀 → 내용 → 꾸미기 → 내보내기** 네 단계로 끝납니다
- 테마 18종, 글꼴 10종, 파트 15종 이상을 조합합니다
- 3D 모델(`.glb`) 뷰어, 무료 사진 검색, 다크/라이트 토글이 기본 제공됩니다
- 결과물은 **단일 HTML** 또는 **폴더 ZIP** 으로 내려받습니다 — 이 저장소가 그 ZIP 그대로입니다
- 만든 프로젝트는 `.pbproj` 로 저장해 두었다가 언제든 다시 불러옵니다
